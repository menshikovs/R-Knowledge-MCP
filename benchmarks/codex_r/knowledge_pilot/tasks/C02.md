# C02 — Widen measurements with duplicate cells

Repair `solution.R` to define `measurements_wide(data)`, using tidyr 1.3.2.
Return one row per sample and one column per analyte. Duplicate sample/analyte
measurements are summed, ignoring missing values; if every value in an
observed cell is missing, that output remains missing. Fill only combinations
with no input row with numeric zero. Preserve the input sample order and order
analyte columns alphabetically. The fixture is `data/measurements.csv`. Do not
install packages.
