# D01 — Find a suitable terminal UI library for R

Choose an R package for a small command-line tool that lets a user navigate
choices with a keyboard, select one or several values, and return stable values
that may differ from displayed labels. Describe what it supports and its
important limits. Consider documentation versions published by 2026-10-25;
use an official CRAN source and package documentation URL. Do not assume there
is only one valid package. `termr` is a candidate to assess, not a mandatory
answer. Save `answer.json` with this shape:

```json
{"r_version":"4.5.2","rationale":"At least 40 characters explaining fit and a tradeoff.","recommendations":[{"package":"...","version":"...","source_url":"...","documentation_url":"...","feature_ids":["..."],"caveat_ids":["..."]}]}
```

Choose one package. Feature IDs: `reactive_terminal_ui`, `headless_app_tests`,
`keyboard_single_multi_select`, `stable_return_values`. Caveat IDs:
`real_terminal_required`, `some_apis_experimental`, `menu_focused`. Use only IDs
that match the package documentation.
