# B03 — Repair invoice line revision handling

Repair `solution.R` so it defines `invoice_totals(lines)`. Duplicate ingestion
of the same invoice, line, and revision is possible; keep one record for each
revision, using the latest `received_at` when duplicate records tie. Select the
highest revision for each invoice and line. If that latest revision is
`cancelled`, omit the line. Sum `quantity * unit_price` for remaining active
lines and return exactly `invoice_id`, `line_count`, and `total`, sorted by
invoice id. Preserve zero and negative quantities. The fixture is
`data/invoice_lines.csv`. Use the installed dplyr version.
