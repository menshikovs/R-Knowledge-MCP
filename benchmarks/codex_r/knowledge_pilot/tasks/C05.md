# C05 — Total downloads over the available cranlogs period

Create `solution.R` defining `cran_download_total(package, fetch)`; `fetch` must
default to `cranlogs::cran_downloads` so the function works with the real
`cranlogs` 2.1.1 package. Query the full available observation period for the
one requested package: the RStudio CRAN mirror logs begin on 2012-10-01, and
the end must be the service's `last-day` value. Use the documented `from` and
`to` interval arguments for this full-range query.

Sum all returned `count` values. Ignore missing counts; return zero for no rows
or no non-missing counts. Return a list with `package`, `total_downloads`,
`from`, `to`, `source`, and `scope`. Identify the RStudio CRAN mirror and state
that this is mirror download traffic, not global CRAN downloads or package
installations. `fetch` is provided with deterministic offline response
fixtures by the scorer; do not make a live HTTP request or install packages.

Official reference: `cranlogs` 2.1.1 reference manual,
<https://cran.r-project.org/web/packages/cranlogs/cranlogs.pdf>. The RStudio
CRAN mirror log start date is documented by the official cranlogs.app API
documentation: <https://github.com/r-hub/cranlogs.app>.
