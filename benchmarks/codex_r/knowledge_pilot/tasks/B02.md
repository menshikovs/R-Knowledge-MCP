# B02 — Carry device state without crossing a batch

Repair `solution.R` so it defines `carry_device_state(events)`. Preserve every
input row and its order, and add `state_filled`. For each `device` and `batch`,
carry the most recent non-missing `state` forward into later missing states.
Never fill backward, across devices, or across batch boundaries. Leave a group
with no prior state as missing. Do not mutate or reorder the input. The public
example is `data/device_events.csv`; hidden cases include empty input and
repeated device/batch keys. Use the installed dplyr/tidyr versions.
