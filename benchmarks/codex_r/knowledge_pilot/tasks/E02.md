# E02 — Small compatible RNA-seq workflow

Implement `run_rnaseq(counts, samples)` in `solution.R`. It must create a SummarizedExperiment-backed count object, fit a two-group DESeq2 model with `control` as the reference and return a list with the fitted object as `dds` and a result data.frame as `results` (gene, log2FoldChange, pvalue and padj columns). Use integer counts and a design that matches the metadata. The scorer supplies fixed local fixtures; do not fetch data, write files or install packages at runtime. Intended environment: R 4.5.2, Bioconductor 3.22, DESeq2 1.50.2 and SummarizedExperiment 1.40.0.
