# B01 — Repair a posted ledger summary

Repair `solution.R` so it defines `ledger_summary(data, from, through)`. The
starter has several defects. `data` has the columns in `data/ledger.csv`;
`from` and `through` are ISO dates. Return a data frame with exactly
`account`, `transactions`, `total`, `first_posted`, and `last_posted`, sorted by
account. Count and sum only rows whose `posted` value is true, whose account is
a nonempty value, whose amount is finite, and whose valid posted date is within
the inclusive date range. Keep negative and zero amounts. `transactions` is the
number of retained rows; first/last are the minimum/maximum retained dates in
ISO form. Return a typed, zero-row data frame with those columns when nothing
qualifies. Use the installed dplyr version and do not install packages.
