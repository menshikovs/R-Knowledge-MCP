# C04 — Repair a cranlogs date-range query

Repair the supplied `solution.R` according to the official `cranlogs` 2.1.1
documentation. It must define `cran_download_total(package, from, to, fetch)`;
`fetch` must default to `cranlogs::cran_downloads` so the function works with the
real package. Keep `package` as one non-empty package name and accept inclusive
ISO dates (`YYYY-MM-DD`) with `from <= to`.

Use `packages`, `from`, and `to` for the requested package and interval. Do not
use `when = "all"`: the documented `when` values are only `last-day`,
`last-week`, and `last-month`; when an interval is supplied, use `from` and
`to`. Sum the returned `count` values, ignore missing counts, and return zero
when there are no rows or no non-missing counts.

Return a list with `package`, `total_downloads`, `from`, `to`, `source`, and
`scope`. Identify the source as the RStudio CRAN mirror and state in `scope`
that this is mirror download traffic, not global CRAN downloads or package
installations. The scorer supplies deterministic offline response fixtures via
`fetch`; do not make a live HTTP request or install packages.

Official reference: `cranlogs` 2.1.1 reference manual,
<https://cran.r-project.org/web/packages/cranlogs/cranlogs.pdf>.
