# C01 — Match the closest prior promotion

Repair `solution.R` using the documented dplyr 1.2.1 join syntax. It must
define `nearest_promo(sales, promos)`: for each sale, match the latest promotion
for the same customer whose `promo_date` is on or before `sale_date`. Do not
match a future promotion. Preserve all sales and their input order; unmatched
sales have missing `promo_id` and `discount`. Return sales with those two
columns appended. The supplied fixture is described in
`data/promo_fixture.json`; all dates are ISO strings. Use `join_by()` and
`closest()` as documented for this pinned version. Do not install packages.
