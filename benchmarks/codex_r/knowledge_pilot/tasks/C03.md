# C03 — Parse European currency amounts

Repair `solution.R` so it defines `parse_euro_amount(x)` with readr 2.2.0.
Parse a numeric amount embedded in text using comma as decimal mark and period
as grouping mark. Preserve order and length. Values with no number, an empty
string, or missing input become numeric `NA`. Return a numeric vector without
parser warnings. The supplied examples are in `data/euro_amounts.csv`. Do not
install packages.
